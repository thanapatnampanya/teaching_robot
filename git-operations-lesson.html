A quick mental model

Git records snapshots. A branch points to a commit. The staging area chooses the next snapshot. A pull request asks to merge a pushed branch into main.

git statusSee what changed and what is staged.
git log --oneline --graph --allInspect local commit history.
git diffSee unstaged changes.
git diff --stagedSee the next commit's selected changes.
